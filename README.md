# Health Risk Classification Using Machine Learning

## Project Overview

This project focuses on predicting the likelihood of diabetes using the **Pima Indians Diabetes Database**. Machine learning classification techniques are applied to patient health indicators to predict whether a patient is likely to have diabetes.

## Dataset

The dataset contains health-related information such as:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

The target variable is **Outcome**, where:

* `0` = No diabetes
* `1` = Diabetes

## Preprocessing

The project includes:

* Data exploration
* Handling missing and invalid values
* Outlier detection and handling
* Feature scaling/normalization
* Train-test splitting

## Machine Learning Models

Two classification algorithms are used:

1. Support Vector Machine (SVM)
2. Decision Tree Classifier

## Model Evaluation

The models are compared using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

Training and testing performance are also compared to discuss **overfitting and accuracy trade-offs**.
